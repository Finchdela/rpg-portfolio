## 🌟 Features

- **📊 Character Sheet & Attributes**: Live gauges for HP (Energy) & MP (Logic/Data), with core metrics (INT, WIS, AGI, CHA, VIT) and custom passives (*K-Means Master*, *Outlier Purifier*, *Community Enchanter*).
- **📜 Quest Log**: Highlights key research and projects, including the *K-Means Clustering of East Java Healthcare Workers* presented at ICDSOS / STIS.
- **🎒 Relic Inventory**: Interactive tech stack equipment cards (Python, Scikit-Learn, Pandas, SQL, Jupyter, Git, Figma).
- **⚔️ Battle Arena (Easter Egg)**: Playable turn-based mini-game vs *Dirty Raw Data & Outliers* with animated HP bars and victory fanfare.
- **🔊 Web Audio Chiptune SFX**: Built-in 8-bit sound effects synthesizer generated purely via Web Audio API (zero external audio files).
- **⚙️ In-App Profile Editor**: Customize stats, quotes, and profile data on the fly.

## 🚀 Live Demo & Deployment

This project is ready to be hosted directly on **GitHub Pages**:

1. Push this repository to GitHub.
2. In your repo, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`!
